For anyone who edits an Astro site

If your site's content lives in Markdown or MDX files, goastro lets you edit it without touching code.

Developers. Hand an Astro site to a client and stop fixing typos for them. They edit posts, dates and tags themselves, and your components and layout stay intact.

Product owners. Update landing pages, release notes and docs yourself, without waiting for a developer. Every change is reviewed before it is saved.

Content managers. Publish and maintain posts, metadata and images in one place, across all your Astro sites, with a backup of every file you change.

Writers and editors. Just write. Headings, links, lists and images work like in a document editor: no asterisks, no hashes, no build errors.

Agencies and freelancers. Give every client a safe way to edit their own content. Nothing is hosted, there are no accounts to manage, and their MDX cannot break.

Docs and marketing teams. Keep Markdown docs and blogs current in any repository, Astro or not, for example a docs/ folder. Each save shows the diff first.

Questions

Is goastro free?

Yes. goastro is open source under the MIT license. There is no account, no paid plan and no limit.

Does it upload my content anywhere?

No. goastro runs on your own computer and edits the files in your project folder. It has no cloud service and sends no data anywhere.

Does goastro collect telemetry or usage data?

No. goastro has no telemetry, analytics or crash reporting, and it only talks to your own computer. Read the details in Privacy and disclaimer, or check the open-source code yourself.

Does goastro publish my site?

No. It saves your changes to the project files. Publish them through your usual workflow, for example a git push or your deploy command.

Will it change my site's code or components?

goastro only writes the content files you save. Imports, components and HTML in your MDX are kept exactly as written during visual edits. You see a line-by-line review before every save, and the old file is backed up first.

Do I need to know Markdown?

No. You edit text like in a word processor: headings, bold, links, lists and images. A Source view is there when you want to see the Markdown.

Can I preview the real page?

Yes, after you save. Preview starts your Astro dev server and shows the saved page as your site renders it, then stops the server when you are done.

Does it work with my Astro theme?

goastro works with Astro sites that keep content in Markdown or MDX, such as content collections and Markdown pages. It detects your folders, fields and page addresses. Other folders of Markdown files open too, for example a docs/ folder.

Which systems does it run on?

Linux, macOS, and Windows through WSL, with Node.js 22.18 or later. Native Windows is not tested yet.

Get started

Free and MIT licensed. Requires Node.js 22.18 or later. Read the full guide →

  1. 1Install goastro once
    npm install -g @goastro/goastro
  2. 2Run it in your Astro project
    cd my-site && goastro

Just trying it? Run npx @goastro/goastro in your Astro project, with nothing to install.
